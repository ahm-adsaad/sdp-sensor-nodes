I. The Battery Problem

Sensor networks monitor the environment in many applications, but battery-powered deployments need periodic battery replacement, which hinders scalable long-term operation.

Most deployed sensor nodes run on batteries or a grid connection. Batteries degrade, and replacing them can be costly or dangerous [1]; nodes are often discarded once their batteries are depleted, even when the hardware still works.

As IoT deployments grow, so does the need for batteries, and periodic battery maintenance limits how far monitoring networks can scale and how sustainable they are.

Solar energy harvesting (EH) lets nodes recharge from ambient sources and extends network lifetime [2], but harvested energy is intermittent [3].

EH, node virtualization and dynamic task assignment have been explored separately; few works implement them together in hardware.

Goal: sustainable power without battery replacement, with every sensing task matched to the energy the nodes have stored.

V. Energy-Aware Node

Harvesting charges the supercapacitor whatever the MCU state. A node sleeps, wakes to listen for tasks, powers its sensors through a load switch only while a task runs, then transmits readings with its energy status.

Virtualization lets one node serve different sensing tasks over time, so each node is used efficiently [9].

VI. Energy-Aware Task Assignment

Each round, the VPS checks that the nodes’ stored energy ei covers every submitted task ej plus a reserve es=egas+etemp kept for future immediate tasks:

∑j∈𝒯imm∪𝒯nonej+es≤∑i=1Sei (1)

If (1) fails, only immediate tasks enter. A MILP then favours costly tasks on nodes with a high remaining-energy share Pi, giving each task at most one node and keeping each node within its stored energy.

A two-phase heuristic is also defined: Phase 1 places each immediate task on the highest-energy node that can afford it; Phase 2 packs non-immediate tasks onto fewer nodes to reduce communication overhead, while each node keeps a reserve θ=egas+etemp. Unassigned tasks can be reconsidered once nodes report newly harvested energy.

Safety: a node must not start a task its stored energy cannot cover, and refuses high-power tasks when its supercapacitor runs low.
