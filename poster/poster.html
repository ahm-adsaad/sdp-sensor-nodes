I. Motivation

Battery-powered sensor nodes need periodic battery replacement, which hinders scalable long-term operation; batteries degrade, and replacing them can be costly or dangerous [1]. Energy harvesting (EH) removes the battery, but harvested energy is intermittent.

EH, sensor-node virtualization and dynamic task assignment have been studied separately; few works implement them together in hardware.

II. System Model

III. Sensor Node

Three power domains: 3V3_IN from the PMIC, joined to the core 3V3 rail through a header for the Nordic PPK2 power profiler, and VCC_SENS, which the load switch cuts during sleep to remove sensor quiescent draw.

IV. Node Operation

Harvesting charges the supercapacitor whatever the MCU state. A node sleeps, wakes periodically to listen for tasks, powers its sensors only while a task runs, and transmits readings with its energy status before sleeping again.

V. Task Assignment

A. MILP

Each round, the VPS checks that the nodes’ stored energy ei covers every submitted task ej plus a reserve es=egas+etemp kept for future immediate tasks:

∑j∈𝒯imm∪𝒯nonej+es≤∑i=1Sei (1)

If (1) fails, only immediate tasks enter. The MILP then favours costly tasks on nodes with a high remaining-energy share Pi:

max∑i=1S∑j=1TxijejPi (2)
s.t. ∑i=1Sxij≤1,∀j (3)
∑j=1Txijej≤ei,∀i (4)

with xij∈{0,1} set when task j goes to node i. Constraint (3) gives each task at most one node; (4) keeps each node within its stored energy.

B. Heuristic

Phase 1 places each immediate task on the highest-energy node that can afford it. Phase 2 packs non-immediate tasks onto fewer nodes to reduce communication overhead, while each node keeps a reserve θ=egas+etemp.

  3. sort 𝒮 by energy E(s), descending

  5. if E(s) ≥ C(t) then
  6. assign(s, t); E(s) −= C(t); break
  7. sort 𝒮 by E(s), descendingPhase 2
  8. for s ∈ 𝒮 do
  9. for t ∈ 𝒯non do
  10. if E(s) − C(t) ≥ θ then
  11. assign(s, t); E(s) −= C(t)
  12. return 𝒮 and the unassigned tasks

Unassigned tasks can be reconsidered once nodes report newly harvested energy.

The PPK2 will profile each mode: sleep, wake, SHT41 and ENS160 reads, LoRa Tx and Rx. The network will be judged on packet delivery ratio and energy per transmission; the scheme on task completion rate, latency, task distribution and network lifetime. Safety: a node must not start a task its stored energy cannot cover.

VIII. Toward Resilient Infrastructure

  • Grid-independent nodes and a single long-range gateway suit power- and cellular-limited sites: hazardous gases, temperature and humidity at remote wastewater plants, or humidity and CO2 in greenhouses.
  • Fewer battery replacements at hard-to-reach or hazardous sites lower maintenance cost, keep workers safer and cut battery waste.
  • Supports sustainable-city development such as Sharjah Sustainable City.
