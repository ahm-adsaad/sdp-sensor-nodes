# Surface: EWSERC/SEWA competition poster, sustainability edition

Scope: a second A0 portrait poster (841 x 1189 mm), printed and submitted as PDF, alongside poster/poster.html, which stays unchanged. Mode: Read.
Audience: workshop judges (SEWA, EWSERC, industry, academia) reading at 1-2 m, then up close.
Content: report only (paper/). The sustainability and resilience framing comes from the report's abstract, problem statement, Project Impact section (economic, societal, global), use cases and supercapacitor rationale. No measured results, no captions, no subtitles.
Why it exists: the user judged that poster.html under-weights sustainability for a competition themed "Infrastructure Resilience in Action: Preparing Sharjah for the Future".

## Direction contract

THESIS: The same IEEE poster world as poster.html, re-ordered so the sustainability argument leads: battery waste and risky maintenance, then battery-free harvesting, then where it serves Sharjah's infrastructure, then how energy-aware operation keeps it running. Refuses the infographic-poster default (icon tiles, stat blocks, gradient banners).

OWN-WORLD: DESIGN.md as written: white print ground, near-black ink, AUS maroon #880E12 owning the band and section rules, STIX Two Text and Math, Source Sans 3 only inside diagrams, data palette with fixed meanings. The battery-powered lane is drawn in neutral greys; green stays harvested energy.

STORY: Air quality needs continuous monitoring; batteries degrade, cost and endanger workers to replace, and nodes are discarded with working hardware; solar EH removes the battery but energy is intermittent; the lifecycle comparison shows the difference; the system and the competition's five themes show where it fits Sharjah; the node schedule and energy-aware assignment show how it stays within harvested energy; low-power choices and evaluation targets close.

FIRST VIEWPORT: Full-width maroon title band as in poster.html. Below, three columns; column one opens with I. Motivation; columns two and three carry II. Battery vs. Harvesting: a two-lane lifecycle diagram over a booktabs comparison table.

FORM: brief-pinned IEEE poster; seed: none. No roll was made because the user pinned the form in the request ("ieee poster style").

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
